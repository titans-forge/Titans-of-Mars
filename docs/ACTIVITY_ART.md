# Surface activity art provenance

The `public/assets/colony-activity-atlas.png` bitmap was generated for this game on 2026-10-15 using the built-in OpenAI image-generation tool. It contains utility-rover facings and EVA walking/tool-use poses, with a transparent background and materials chosen to match the existing colony artwork. This is fictional near-future hardware. No claim is made that it depicts a flown rover or an approved spacesuit design.

The original generated PNG is used without bitmap edits. Actual dimensions are 1254 × 1254 pixels, RGBA. The renderer defines explicit 313/314-pixel frame bounds rather than assuming a 1024-pixel sheet. Rover rear and EVA northeast views reuse mirrored facings; walking has two alternating distance-driven phases. These are 2D sprites, not skeletal or physically simulated animation.

The surface renderer uses simulated assignments and commissioned structures to select jobs. Its elapsed visual clock never awards resources or construction progress. Rovers take free-cell routes and stop at service positions; crew shelter during dust/debris hazards. Pausing or reduced motion stops visual travel. Construction changes stage from the saved work ledger and begins supplying the grid only after commissioning.

Existing license and media-rights documents are unchanged in this pass. Licensing decisions are deferred at the user's request. The generation prompt and original output path are retained in the local activity-pass evidence folder.
